Entry for the make.fun bounty [The Internet in One Word](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b).

The program writes one word — the whole internet in a single word — to
`/output/entry.txt`, where the competition's gate scorer reads it. Run it
with `python3 main.py`.
